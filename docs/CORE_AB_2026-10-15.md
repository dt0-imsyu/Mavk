# Mavk Core: first same-workload A/B

## Implemented

Separate C++17 static resource/submission library, no JNI or Android dependency.
Harness owns device/queue/WSI; Core owns buffers, images, shader modules,
pipelines, fences and command batches. No hidden frame copies, command remoting,
feature emulation or per-resource wait-idle. See core/README.md for lifetime rules.

Original direct native compute remains a control. Comparison uses one actual
Mali-G925 device/queue per process and identical shader, descriptor layout,
dispatch, barriers, memory selection and result verification. Both paths call
the same system Vulkan driver. All validation results below are application
correctness checks, **not a Vulkan validation-layer PASS**.

## Compute and image transfers

Three independent app processes; ABBA (direct/Core/Core/direct) per size;
128 compute rounds/arm, first16 discarded only for timing, all results checked.
GPU timestamps use identical command spans. Creation/teardown measured separately.

- 509,607,936 uint32 outputs checked, no mismatch.
- 243,695,616 RGBA8 image pixels checked, no mismatch.
- Buffers:4096,65536,262144 words.
- Images:64×64,640×360,1920×1200. Clear/transfer/readback tests, not triangle
  rasterization at each of these sizes.
- Core live counters zero after every phase; no claim of independent leak detection.
- Median of run-level Core-minus-direct p50 record+submit: -5.308,+5.307,+1.847µs
  respectively. Variation at these scales includes scheduling/DVFS; a negative
  delta is not proof of Core acceleration, nor is a small delta zero overhead.

## Remaining gates / exact next step

Core foundation and bounded correctness/overhead A/B exist. Full M0/M1 is not
declared complete. Next: bounded Surface recreation/lifecycle checks and app-local
Vulkan synchronization validation, without global graphics overrides. Include
graphics timestamps/repeated-resolution rasterization if drawing overhead is
needed; do not restart broad triangle performance exploration.

Only after these gates move to a narrow guest/host command bridge. This native
layer is not a Vulkan ICD, WDDM driver, DXVK compatibility layer or guest GPU.
No U-AVF APK, VM, firmware, CPU, storage or H.264 path was changed by these tests.
