## Actual code and gates

`droiddeck-ahb-app-selection.patch` applies cleanly to the current external fork.
It adds the experimental preference in the existing Mavk settings group, cold
compositor preparation in SessionActivity before startOrAttach, and the bundled
launch-policy/environment selection in MavkExperimental. Mali + selected Mavk,
default system Vulkan, Steam/run mode and SDR are required. Receipt, executable
policy and library hash are checked. Invalid dimensions or unavailable component
leave SHM selected. Switching on after the compositor has already initialized
requires a full app restart; it does not pretend that a marker upgrades a live
Wayland global. Switching off selects explicit SHM on the next launch.

The existing Steam compatibility asset now honors the already-tested optional
launcher override for both wrapper families. SessionFiles stages this asset
through its existing mechanism; no active Steam wrappers or account files were
regenerated by this test. The launcher remains the original default when the
override is absent. No Adreno/Turnip selection changes.

All three changed Kotlin sources compiled against real resolved dependencies,
Android 36, Kotlin/Compose compiler 2.1.0, JVM target17 and cached application
classes. Initial offline classpath export failed due to missing cached metadata;
online metadata resolution succeeded. Configuration-cache was disabled and
project build outputs redirected to C:. No full native build was required.

The DEX overlay retains the installed APK33 classes rather than rebuilding old
cached classes for unrelated sources: 37922 retained classes, 288 replaced source
classes, 290 newly compiled classes, zero removed class names, two rewritten DEX
members. 485 other APK members remained byte-identical. Runtime/launch-hook
asset rollup then changed exactly its three requested assets, verifying the
other 485 members unchanged. Native libraries remain APK33's existing binaries.
