# Mavk — текущая работа

## Текущий шаг: CullDistance после tessellation

Общий компилятор теперь обрабатывает выход TES,слой добавляет GS в настоящий
пятистадийный pipeline. На Mali прошли4режима/98304байта,включая частичное
отсечение полученного веера:96из288пикселей. Прежний PrimitiveId,26GPU-регрессий
и меню/настройки/ввод Muck PASS. Рабочий APK25 не заменён,feature bit остаётся
false: существующая GS и другие контракты ещё не реализованы полностью.
Steam штатно возобновлён после выхода0; нынешний заряд100%. Без commit/push.

## Текущий шаг: PrimitiveID после отсечения

Добавлена общая передача исходного ID примитива через вставленную GS в fragment
shader. На Mali доказано: отсечение первого/среднего/последнего треугольника не
перенумеровывает оставшиеся,новый draw сбрасывает ID.393216байт/4режима PASS;
прежние блоки и26регрессий PASS. APK25 не менялся,feature bit остаётсяfalse:
полная CullDistance/обычный DXVK ещё не объявляются рабочими. Без commit/push.

## Текущий шаг: обычная Location всего блока

Убрано ограничение на общую Location пользовательского блока. На G925 проверен
блок с ненулевой базой4,цветом,flat int и массивом:131072байта совпали с эталоном.
На том же кандидате прошли прежние блоки и все26GPU-регрессий. APK25 и рабочие
системы не менялись. Полная CullDistance ещё не объявляется: остаются реальные
ограничения стадий/интерфейсов. Результат — PROGRESS,не завершение общей цели.

## Новый шаг: пользовательские блоки между стадиями

Общий CullDistance-компилятор сохраняет структуру блоков данных через добавленную
geometry-стадию. На G925 проверены цвет, flat int и массив: четыре режима,
131072 байта совпали с независимым эталоном. Все26старых GPU-регрессий PASS.
APK25 не заменён, публичный feature bit остаётсяfalse. Это развитие общей
семантики, не исключение под игру и не полный Vulkan/CTS PASS.

## Новый шаг: автоматическое подключение CullDistance

Слой сам преобразует исходный VS/FS при создании pipeline; ручная подготовка
шейдеров приложением больше не нужна в экспериментальном режиме. Четыре
GPU-режима,включая UBO и защитную инструментацию,прошли сравнение131072байтов.
Проверен явный отказ без native geometry.26регрессий и меню/Settings/ввод Muck
на кандидате PASS. APK25 не заменялся,override убран,Steam оставлен открытым.
Это частный диагностический режим,не полная публичная Vulkan-возможность:
feature bit остаётсяfalse,обычный DXVK пока не прошёл admission. Commit/push нет.

## Новый функциональный шаг: целопримитивный CullDistance

Добавлен общий компилятор преобразования VS->GS->FS: Mali аппаратно отбрасывает
целый примитив по cull-плоскостям,не отдельные фрагменты.8GPU-случаев прошли
сравнение с независимым эталоном в обычном и защищённом режимах слоя,
65536байтов без расхождений. Прежний renderer без GS тоже прошёл регрессии.
Это первый работающий механизм одного из P0 обычного DXVK,но не закрытый
feature:автоподключение к Vulkan pipelines,другие стадии/топологии и полная
семантика ещё нужны. shaderCullDistance не объявлен,APK25 не менялся.
Дальше — интеграция с реальным pipeline,не увеличение числа Suite-тестов.

## Актуально: APK25 — трассировка только по запросу

Убраны постоянные подробные сообщения на каждую команду; ошибки и итоговые
счётчики сохранены. В контролируемом тесте запись команды занимает медианно
3,29мкс без трассировки против6,59мкс с ней. Это не удвоение игровых FPS.
Все26GPU-проверок прошли через установленный runtime, Muck показывает меню/
Settings и принимает ввод, Steam сохранён. APK24 оставлен для отката.
Доработка логирования завершена; следующий этап — функциональная совместимость,
не новые варианты диагностики. Production U-AVF не менялся,commit/push нет.

## Актуально: APK24 — убраны лишние диагностические чтения

сообщения. Исправлено без отключения защитных проверок. Включённые отчёты
по-прежнему получают реальные ошибки доступа. Все 26 GPU-проверок прошли
через установленный общий runtime; Muck показывает меню/Settings, ввод работает.
Steam оставлен открытым, APK23 сохранён для отката. Исходные ассеты согласованы.
Прирост FPS не измерен; устранена доказанная лишняя работа, не заявлено решение
всех проблем производительности. Production U-AVF не менялся, commit/push нет.

## Актуально: APK23 установлен и проверен — 22 октября

Исправлена общая обработка недостающих компонентов texel-форматов: за границей
R/RG-ресурса возвращается правильная альфа, а null-дескриптор остаётся нулевым.
Формат берётся из настоящего VkBufferView; перекомпиляции под каждый view нет.
Все 26 GPU-сценариев прошли через установленный общий runtime. Muck без
индивидуального слоя показывает меню/Settings и принимает ввод; Steam сохранён.
APK22 оставлен для отката. Исходные ассеты и сборочные зависимости согласованы.

Отчёт DeepSeek проверен отдельно: его сохранённые результаты полезны, но
standalone SPIR-V не проверяет hook слоя. У его verifier кейса D найден пробел:
ошибка печатается без ненулевого exit code; сами сохранённые данные D верны.
Это не доказательство полной совместимости Mavk. CTS/FPS не измерялись,
полные feature bits не включались. U-AVF/Windows/Ubuntu не изменялись.

## Актуально: APK20 установлен и проверен

Новый обычный runtime bfc10a4c содержит общий пакет aggregate/CopyMemory,
Vulkan 1.2, копии указателей и texel image operands. Все 22 GPU-сценария прошли
внутри установленного APK20. Steam показывает библиотеку через Zink/Mali;
Muck штатно открыла меню и Settings без индивидуального выбора слоя.
Меню кандидата: 12,8 screen updates/s против 13,3 у APK19; это не точный
performance A/B и не измерение всех уникальных кадров. APK19 сохранён.

Сейчас проверяется следующий кандидат, не включённый в APK20: signed/unsigned
индексы в сгенерированной арифметике защиты создавали неверный UMulExtended.
Storage-texel пример воспроизвёл ошибку на host; после исправления SPIR-V
валиден, пять bounds-checks сохранены, host-регрессии прошли. ARM frontend
f0a0c057 собран; идёт сборка отдельного слоя для GPU.

## История texel-пакета

Новый общий фикс texel-buffer защиты прошёл Mali: флаги None/ZeroExtend больше
не отключают проверку границ. ZeroExtend уже выдаёт обычный glslc для uint
текстур; это не специальный случай игры. 512 компонентов и все 21 прежний
GPU-сценарий прошли. Кандидат 743d9d6c, установленный APK19 не заменён.
Интеграционная проверка Muck этого кандидата выполняется.
TEXEL_OPERANDS_2026-10-21.md содержит точную область и артефакты.

Прямое копирование буферов OpCopyMemory подключено к тому же механизму и прошло
GPU-проверку. Итого 19 сценариев без ошибок; отдельный прогон пяти форм
составного доступа проверил 960 значений.

Пакет составных операций сохранён отдельным кандидатом. Реальная Muck создала
D3D11-устройство и swapchain, выполнила 202826 защищённых команд без отмеченных
ошибок Mavk. Это фоновая проверка, а не подтверждение картинки или FPS.
В установленный APK19 этот пакет пока не включён.

Следующая ограниченная правка уже прошла host-проверки: корректный выбор
Vulkan 1.2/SPIR-V и раздельные параметры чтения/записи при копировании буферов.
Проверка на Mali завершена: новый сценарий и 19 прежних прошли; отдельно
проверены 1152 значения в шести формах составного доступа. Пакет сохранён.

Следующая проверка относится к обязательной семантике robustBufferAccess2:
как Mali реально обрабатывает выход за границы vertex buffer. Два формата,
три начальных индекса, 1536 компонентов прошли и через Mavk, и без него:
в проверенных случаях достаточно штатной обработки Mali. Это не доказательство
всего vertex-контракта. Никакие feature bits для допуска обычного DXVK
не подменяются. Результат: VERTEX_ROBUSTNESS_2026-10-21.md.

Найден и исправлен на host ещё один конкретный обход защиты: копия указателя
через OpCopyObject. До исправления валидный шейдер не получал проверок границ,
после нормализации проверки появились. ARM64-кандидат прошёл новый и 20 прежних
GPU-сценариев, плюс 1152 значения составных операций. Muck создала D3D11 device
11_0 и выполнила 81534 защищённые команды без отмеченных ошибок Mavk.
Проверка фоновая: FPS/картинка не подтверждены. Игра остановлена, временный
выбор слоя убран; обычный runtime APK19 сохранён. Подробности:
COPIED_POINTERS_2026-10-21.md.
